# 🌸 شامل لإدارة مراكز وفروع التجميل والعناية (Shamel Beauty ERP)

> منظومة إدارية ومحاسبية سحابية متكاملة متعددة المراكز والفروع (Multi-Tenant ERP) مصممة خصيصاً لمراكز التجميل، صالونات العناية بالبشرة والشعر، وعيادات الجلدية والتجميل.

---

## 📑 نبذة عن النظام
تم بناء النظام ليوفر حلاً شاملاً لكل جوانب الإدارة اليومية والمالية لمراكز التجميل:
- 👑 **لوحة تحكم المطور والاشتراكات:** إدارة أصحاب المراكز، تفعيل التراخيص، ومتابعة مبيعات الفروع وعمولات المطور.
- 🏢 **تعدد المراكز والفروع (Multi-Tenant):** كل مركز رئيسي يدير فروعه وموظفيه بشكل منفصل ومعزول تماماً.
- ⚡ **طابور الانتظار والشاشة التفاعلية:** تسجيل العملاء، نداء صوتي باللغة العربية، وحساب أوقات الانتظار.
- 🧾 **نظام فواتير وكاشير POS ذكي:** إصدار فواتير حرارية (80mm) وفواتير A4 رسمية مع رمز الاستجابة السريع QR ومتوافقة مع متطلبات الضرائب.
- 💰 **الخزينة والمالية والتقارير:** تتبع الإيرادات، المصروفات، الأرباح، وسندات الصرف مع فلاتر حسب التاريخ وطرق الدفع.
- 💄 **إدارة الخدمات وباقات التجميل:** ضبط قوائم الأسعار، العروض، وتحديد العمولات ونقاط الولاء التلقائية.
- 📦 **المستودع والمخزون:** جرد المستحضرات ومنتجات العناية وتنبيهات مستويات النواقص وتواريخ الصلاحية.
- 👥 **شؤون الموظفين والرواتب:** دليل الموظفين، مسير الرواتب، السلف، الخصومات والمكافآت، ونسب عمولات الخدمات.
- 📅 **المواعيد وبوابة الحجز أونلاين:** جدول حجوزات المواعيد مع صفحة خارجية مستقلة للعملاء للحجز عبر الإنترنت.
- 🛡️ **منظومة أمان وصلاحيات دقيقة:** تحكم كامل في صلاحيات كل موظف وكل زر (طباعة، تصدير Excel وPDF، تعديل، حذف، وقراءة فقط ReadOnly).
- 💾 **النسخ الاحتياطي والاستعادة:** تصدير واستيراد قواعد البيانات بنقرة زر بصيغة JSON أو Excel متعدد الأوراق.

## 🖥️ تحويل وتشغيل المشروع كتطبيق سطح مكتب (Electron Desktop App)
ملفات الـ Desktop جاهزة ومدمجة بالفعل داخل المشروع (`electron.cjs` و `electron/preload.cjs` و `electron-builder.json`).

### 1. تثبيت حزم Electron (في حال عدم تثبيتها مسبقاً):
```bash
npm install -D electron electron-builder concurrently wait-on
```

### 2. تشغيل التطبيق في وضع سطح المكتب المباشر (Desktop Dev Mode):
```bash
npm run electron:dev
```

### 3. بناء ملف التثبيت (.exe لـ Windows أو dmg لـ Mac):
```bash
# بناء نسخة Windows الكاملة (.exe)
npm run pack:win

# بناء لجميع المنصات
npm run electron:build
```
سيكون ملف التثبيت المكتبي جاهزاً ومحفوظاً داخل مجلد `release/` لتوزيعه على أجهزة الكاشير والمراكز مباشرة.
